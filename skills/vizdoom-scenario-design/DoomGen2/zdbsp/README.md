# ZDBSP

ZDoom's internal/external node builder.

- Copyright (C) 2002-2006 Randy Heit and ZDoom contributors
- License: GNU General Public License v2.0 or later (see `LICENSE`)
- Upstream source code: <https://github.com/ZDoom/zdbsp>

ZDBSP is optional for ViZDoom: if unavailable on the host platform (for example on Linux or
Intel macOS), DoomGen2 skips node building and ViZDoom builds nodes at map load time.
